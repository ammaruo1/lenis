# النظام البصري والحركي — «الجيل العربي الرقمي»

> **الفكرة:** الموقع يُباع بالعين قبل الكلمات. الزائر يتحكم بالمنتج بإصبعه: يديره، يفتحه، يكبّره، ويرى مواصفاته تظهر فوقه أثناء التمرير.
> البيانات (ملف 01) والحركة (هذا الملف) **ركيزتان متساويتان**. الحركة هنا تحمل البيانات وتقدّمها.

---

## 1. المبادئ الخمسة

1. **المنتج هو البطل.** كل مشهد كبير يدور حول جهاز حقيقي بصورة عالية الجودة.
2. **التمرير هو المخرج.** الزائر يتحكم بالسرعة، والحركة مربوطة بإصبعه (scrub) وليست فيديو يعمل وحده.
3. **كل حركة تكشف معلومة.** المنفذ يضيء ومعه اسمه، البطارية تمتلئ ومعها الساعات.
4. **قوة بلا ثقل.** الإبهار لا يعني بطئًا. الموقع يجب أن يعمل على جوال متوسط وإنترنت اليمن.
5. **لكل مشهد بديل ثابت.** إن ضعف الجهاز أو الشبكة، يظهر المنتج بصورة جميلة ثابتة.

## 2. خط الصور (Image Pipeline)

### 2.1 المصدر: الأهم في الموضوع كله
جودة الحركة تتبع جودة الصور. وهذه **الصور الحقيقية** هي ما سيميّزكم.

| المصدر | الاستخدام | ملاحظة |
|---|---|---|
| **تصوير المتجر نفسه** (جوال حديث + إضاءة + خلفية موحدة) | كل المنتجات المعروضة | الأفضل: يثبت أن الجهاز موجود فعلًا |
| صور الشركة المصنّعة (Press Kit) | للمنتجات الجديدة | تحقق من الترخيص |
| مواد توضيحية مرسومة (SVG / 3D) | رسوم التوصيل والمخططات | تُوسَم «توضيحية» |
| صور مولّدة بالذكاء الاصطناعي | خلفيات وأجواء فقط | **لا تُعرض كأنها صورة جهاز بيع** |

> ملف `public/images/sources.json` الحالي يوثق مصادر الصور. راجع ترخيص كل صورة قبل النشر، واستبدل ما لا ترخيص له.

### 2.2 قائمة اللقطات لكل منتج (Shot List)
1. أمامية مغلق · 2. ¾ يمين · 3. ¾ يسار · 4. جانبي نحيف
5. مفتوح والشاشة تعمل · 6. الكيبورد من قرب · 7. المنافذ يمين · 8. المنافذ يسار
9. الخلف · 10. ملصق الموديل/الرقم التسلسلي (إثبات) · 11. أي خدش أو عيب (للدرجة B/C)
12. **تسلسل دوران 360°** (القسم 3)

### 2.3 المعايير التقنية
- **ماستر:** 2400px للجانب الأطول، خلفية موحدة أو شفافة.
- **الخلفية:** عزل المنتج (cutout) بخلفية شفافة للمشاهد الكبرى، لوضع ظل وخلفيات متغيرة خلفه.
- **التصدير:** AVIF أولًا، WebP بديلًا، مع `srcset` بثلاثة أحجام: 480 / 960 / 1600.
- **الوزن المستهدف:** بطاقة ≤ 40KB · صورة صفحة منتج ≤ 120KB · Hero ≤ 200KB.
- **التسمية:** `{product-id}-{shot}-{size}.avif` مثل `lap-t490s-001-34left-960.avif`.
- **اللون:** ملف ألوان sRGB موحد، وإضاءة متناسقة بين المنتجات (نفس الخلفية والزاوية).

### 2.3 أدوات العزل والتجهيز
- عزل الخلفية: remove.bg أو Photoshop/Photopea أو Clipping في Affinity.
- التحويل الجماعي: `sharp` (Node) أو `squoosh-cli`، يُدمج في سكريبت `npm run images`.

## 3. تسلسلات الحركة (Frame Sequences) — سر الإبهار

هذه التقنية التي تستخدمها المواقع الكبرى لعرض المنتج: **مجموعة صور متتالية تُرسم على Canvas، يتقدم رقم الإطار مع التمرير.**

### 3.1 الأنواع المطلوبة
| التسلسل | الإطارات | الاستخدام |
|---|---|---|
| **دوران 360°** للمنتج | 36–72 | سحب بالإصبع/الفأرة + مشهد في الصفحة الرئيسية |
| **فتح اللابتوب** (مغلق ← مفتوح) | 60–90 | مشهد Hero المثبّت |
| **تفكيك (Exploded)** للمكونات | 60–90 | شرح الرام/SSD/البطارية (اختياري) |
| **اتصال الأجهزة** | 60 | مشهد «تقنيتك تعمل معًا» |

### 3.2 كيف تُنتَج
1. **أسهل طريقة:** منصة دوّارة (Turntable ~15$) + جوال على حامل + فيديو 10–15 ثانية دورة كاملة.
2. استخراج الإطارات:
```bash
# 60 إطارًا بعرض 1280px بصيغة WebP
ffmpeg -i turntable.mp4 -vf "fps=6,scale=1280:-1" -c:v libwebp -quality 78 frames/frame_%03d.webp
```
3. تُحفظ في `public/sequences/{id}/frame_001.webp ...` ومعها `manifest.json` (عدد الإطارات، العرض، الارتفاع).

### 3.3 ميزانية الوزن (مهمة جدًا)
- حاسوب: 60–90 إطارًا × 1280px ≈ 25–50KB للإطار → **≤ 3MB للتسلسل**.
- جوال: 30–40 إطارًا × 720px → **≤ 1MB**.
- **التحميل التدريجي:** حمّل أولًا كل 4 إطارات (عرض مقبول فورًا)، ثم أكمل الباقي في الخلفية.
- لا يُحمَّل أي تسلسل إلا عند اقتراب المشهد من الشاشة (`IntersectionObserver` أو `ScrollTrigger` بـ `once`).

### 3.4 المكوّن الأساسي (Scroll Frame Sequence)

```tsx
// src/components/motion/FrameSequence.tsx
import { useEffect, useRef } from 'react';
import { gsap } from 'gsap';
import { ScrollTrigger } from 'gsap/ScrollTrigger';
gsap.registerPlugin(ScrollTrigger);

type Props = { base: string; count: number; poster: string; scrollLength?: string };

export function FrameSequence({ base, count, poster, scrollLength = '+=250%' }: Props) {
  const wrap = useRef<HTMLDivElement>(null);
  const canvas = useRef<HTMLCanvasElement>(null);

  useEffect(() => {
    const cvs = canvas.current!, ctx = cvs.getContext('2d')!;
    const lite = matchMedia('(prefers-reduced-motion: reduce)').matches
      || (navigator as any).connection?.saveData
      || (navigator.hardwareConcurrency ?? 8) <= 2;
    if (lite) return; // يبقى الـ poster الثابت ظاهرًا

    const step = innerWidth < 768 ? 2 : 1;                 // جوال: كل إطار ثانٍ
    const files = Array.from({ length: count }, (_, i) => i).filter(i => i % step === 0);
    const imgs: HTMLImageElement[] = [];
    const state = { frame: 0 };
    let last = -1;

    const draw = (i: number) => {
      const img = imgs[i]; if (!img?.complete || i === last) return;
      const r = Math.min(cvs.width / img.width, cvs.height / img.height);
      ctx.clearRect(0, 0, cvs.width, cvs.height);
      ctx.drawImage(img, (cvs.width - img.width * r) / 2, (cvs.height - img.height * r) / 2, img.width * r, img.height * r);
      last = i;
    };
    const size = () => {
      const dpr = Math.min(devicePixelRatio, 2);
      cvs.width = cvs.clientWidth * dpr; cvs.height = cvs.clientHeight * dpr; last = -1; draw(Math.round(state.frame));
    };

    files.forEach((n, k) => {                               // تحميل: أول إطار فورًا
      const img = new Image(); img.src = `${base}/frame_${String(n + 1).padStart(3, '0')}.webp`;
      if (k === 0) img.onload = () => { size(); draw(0); };
      imgs.push(img);
    });

    const ctxGsap = gsap.context(() => {
      gsap.to(state, {
        frame: imgs.length - 1, snap: 'frame', ease: 'none',
        scrollTrigger: { trigger: wrap.current, start: 'top top', end: scrollLength, scrub: 0.5, pin: true },
        onUpdate: () => draw(Math.round(state.frame)),
      });
    }, wrap);

    addEventListener('resize', size);
    return () => { removeEventListener('resize', size); ctxGsap.revert(); };
  }, [base, count, scrollLength]);

  return (
    <div ref={wrap} className="relative h-screen">
      <img src={poster} alt="" className="absolute inset-0 h-full w-full object-contain" />{/* بديل ثابت */}
      <canvas ref={canvas} className="absolute inset-0 h-full w-full" aria-hidden="true" />
    </div>
  );
}
```
> الوكيل يطوّر هذا المكوّن (تحميل تدريجي، تنظيف الذاكرة، مؤشر تحميل)، لكن المبدأ كما هو: **Canvas + إطار يتبع التمرير + poster بديل.**

## 4. كتالوج المشاهد (Scene Catalog)

### 4.1 الصفحة الرئيسية

| # | المشهد | ماذا يحدث | البيانات المرافقة |
|---|---|---|---|
| 1 | **Hero** | المنتج يدخل بطبقات (parallax) وإضاءة، النص يظهر كلمة كلمة، المنتج يميل مع الفأرة/الجيروسكوب | الشعار + 3 أرقام حقيقية |
| 2 | **اللابتوب يُفتح** (Pinned) | تسلسل الفتح مربوط بالتمرير، وعند إطارات محددة تظهر لافتات: المعالج، الشاشة، المنافذ، البطارية | مواصفات المنتج المميز من البيانات |
| 3 | **«تقنيتك تعمل معًا»** (Pinned) | الأجهزة تدخل واحدًا بعد آخر (لابتوب ← شاشة ← سماعات ← راوتر)، وخطوط SVG تُرسم بينها وتضيء | قائمة التجهيز + «يعمل مع» |
| 4 | **التجهيزات** (أفقي) | تمرير عمودي يتحول إلى حركة أفقية بين 4 مكاتب، كل مكتب تُركَّب مكوناته | مكونات كل باقة وسعرها |
| 5 | **الفئات** | بطاقات بصور كبيرة، تكبير تدريجي مع التمرير، ميلان 3D عند اللمس | عدد منتجات كل فئة |
| 6 | **وصل حديثًا** | بطاقات تدخل بتتابع، ودوران 360° مصغّر عند التحويم | بطاقة بيانات كاملة |
| 7 | **الماركات** | شريط متحرك (Marquee) يبطئ عند التحويم | العلامات المتوفرة |
| 8 | **الأرقام** | عدّاد يعدّ عند الظهور | أرقام من البيانات فقط |

### 4.2 صفحة المنتج (الأهم)
1. **معرض ذكي:** سحب بين الصور، تكبير بالإصبعين/النقر، وزر **«أدِر الجهاز 360°»**.
2. **نقاط ساخنة (Hotspots):** نقاط على الصورة (منفذ، كاميرا، كيبورد) تفتح معلومة عنها.
3. **مواصفات ملتصقة (Sticky):** تبقى المواصفات بجانب الصور أثناء التمرير، ويُضاء الصف المقابل للصورة الظاهرة.
4. **مشهد البطارية:** شريط يمتلئ حتى صحة البطارية الفعلية.
5. **انتقال مشترك:** عند فتح المنتج من القائمة تطير صورته من البطاقة إلى مكانها في الصفحة (View Transition + `view-transition-name`).

### 4.3 صفحات أخرى
- **المتجر:** الفلاتر تحرّك البطاقات بانسياب (GSAP Flip) بدل القفز.
- **التجهيزات:** المكتب يُركَّب مكونًا بعد مكون عند التمرير، وكل مكوّن قابل للنقر ليفتح منتجه.
- **الضمان:** درجات الحالة A/B/C كشريحة قبل/بعد (Slider) توضح الفرق بصريًا.
- **الأدلة:** شريط تقدم القراءة + صور تتحرك ببطء (parallax خفيف).
- **حاسبة UPS:** الأجهزة تُسحب إلى الـ UPS ويمتلئ عدّاد الواط حيًا.

### 4.4 عناصر عامة
- مؤشر الفأرة المخصص (موجود) يتحول حسب العنصر: «اسحب» على الصور، «افتح» على البطاقات.
- أزرار مغناطيسية (موجودة).
- أنماط تحميل (Skeleton + Blur-up) بدل الشاشة الفارغة.
- كل ما فوق: على الجوال أخف، وبلمس الإصبع بدل المؤشر.

## 5. تقنيات الحركة المعتمدة

| التقنية | الاستخدام |
|---|---|
| **GSAP ScrollTrigger** | المشاهد المثبتة والـ scrub والأفقية |
| **GSAP Flip** | تغيير ترتيب البطاقات والانتقالات بين الحالات |
| **GSAP SplitText** | كشف النصوص (**انتبه للعربية: القسم 6**) |
| **GSAP Observer** | سحب 360° وإيماءات اللمس |
| **Lenis** | التمرير الناعم، متزامن مع ScrollTrigger |
| **Canvas 2D** | تسلسلات الإطارات |
| **CSS Scroll-driven Animations** | حركات بسيطة بلا JS (تحسين تدريجي) |
| **View Transitions API** | الانتقال بين الصفحات والصور المشتركة |
| **SVG (stroke-dashoffset)** | رسم خطوط التوصيل |
| **three.js / @react-three/fiber** *(اختياري)* | نموذج 3D للـ Hero على الحاسوب فقط، يُحمَّل كسولًا |

> مكتبات GSAP بإضافاتها، ومنها SplitText، صارت مجانية الاستخدام. راجع الترخيص الحالي في موقع GSAP قبل الاعتماد.

## 6. العربية والاتجاه: فخاخ تقتل الحركة

1. **ممنوع تقطيع النص العربي إلى حروف.** تقطيعه بالحرف يكسر اتصال الحروف فيظهر مشوّهًا. قسّم **بالكلمة أو بالسطر** فقط. (الإنجليزية يمكن تقطيعها بالحرف.)
2. **الحركة الأفقية تنعكس:** في RTL يدخل المحتوى من اليمين. اربط الاتجاه بـ `dir` في الصفحة.
3. **التمرير الأفقي المثبّت:** يبدأ من اليمين في العربية.
4. **الأسهم والشرائح (Sliders)** تنعكس.
5. أرقام الإحصاءات تُعرض بنفس نظام الأرقام في المتجر (غربية أو هندية) باتساق.

## 7. الأداء: الحركة القوية تحتاج انضباطًا

| القاعدة | التطبيق |
|---|---|
| حرّك `transform` و`opacity` فقط | لا تحريك `width/top/box-shadow` |
| تحميل كسول لكل مشهد ثقيل | `dynamic import()` + IntersectionObserver |
| سقف دقة Canvas | `devicePixelRatio ≤ 2` |
| ارسم فقط عند تغيّر الإطار | تجنب الرسم المتكرر |
| وضع الخفيف | عند `saveData` أو `prefers-reduced-motion` أو جهاز ضعيف: يظهر الـ poster الثابت |
| جوال | إطارات أقل، دقة أقل، بلا 3D، بلا pin ثقيل |
| تنظيف الذاكرة | `ctx.revert()` عند إلغاء التركيب، وتحرير الصور |
| صفحة المنتج | لا يُحمَّل تسلسل 360 حتى يضغط الزائر الزر |

**مقاييس القبول:** LCP ≤ 2.5s · CLS ≤ 0.1 · INP ≤ 200ms · 60fps على جوال متوسط · وزن الصفحة الأولى ≤ 1.5MB قبل المشاهد الكسولة.
