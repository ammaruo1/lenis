# سجل تغييرات نظام الإدارة

## 2026-10-02 — المرحلة A

- مساحات عمل npm داخل المستودع الفعلي `lenis/`، مع مخططات كتالوج مشتركة مطابقة للمخططات السابقة وإعادة تصدير من المسار القديم.
- مخطط Prisma لكل وحدات الهوية والكتالوج والمحتوى والأشخاص والمبيعات والجمهور، مع ترحيل أولي وفهارس وقيود بيانات.
- API للمصادقة والجلسات وتغيير كلمة المرور وTOTP وإدارة الموظفين وسجل التدقيق، وصلاحيات مفروضة على الخادم.
- واجهة إدارة منفصلة تحت `/admin/`، عربية/إنجليزية وRTL/LTR ومظهر فاتح/داكن، مع قائمة هاتفية وصفحات 403 و404 وحوارات تأكيد وإشعارات.
- تهيئة أسرار محلية عشوائية وأمر CLI تفاعلي لإنشاء المالك؛ لا توجد حسابات أو بيانات أعمال افتراضية.
- تجهيز Docker للتطوير، واختبارات وحدات وتكامل وواجهة. نتائج التشغيل الفعلية في `ADMIN-REPORT-A.md`.

المرحلة A لا تربط المتجر بالـAPI ولا تتيح تحرير المنتجات أو إدخال العملاء. تُنفذ هذه الوظائف في مراحل B–E حسب الطلب الأصلي.

## 2026-10-02 — تشغيل Windows دون Docker

- أُضيف `npm run dev:local` لاستخدام PostgreSQL المثبت على Windows، مع حفظ قاعدة التطوير على E عند توفره، وتطبيق الترحيلات وتشغيل API والواجهة على loopback.
- أُضيف `npm run db:local:stop` للإيقاف الآمن مع الاحتفاظ بالبيانات، ودليل `ADMIN-LOCAL-WINDOWS.md`.
- لا ينشئ المشغّل حساب مالك تلقائيًا؛ يبقى إنشاؤه التفاعلي عبر `npm run seed:owner` مطلوبًا ببيانات المالك الفعلية.
